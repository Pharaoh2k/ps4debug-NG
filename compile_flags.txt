# clangd/pi-lens configuration for the ps4debug-NG payload sources.
#
# The payload only compiles inside the vendored ps4-payload-sdk include paths
# (debugger/Makefile: -I$(LIBPS4)/include -I. -Iinclude ...). Without this file
# every SDK-provided type/macro reads as unknown to clangd-based tools.
#
# Host-header conflicts, renamed for navigation only (the release build uses
# -nostdlib + FreeBSD-targeted headers where these don't collide):
# - __dev_t: FreeBSD-internal type used by the SDK's file.h; absent from UCRT.
# - the symbols below: libPS4 declares them as function pointers, colliding
#   with the host UCRT declarations.
# int-conversion warnings are pre-existing payload idioms (errno = NULL,
# dlsym-style void* to integer) accepted by the release gcc build.

-D__dev_t=dev_t
